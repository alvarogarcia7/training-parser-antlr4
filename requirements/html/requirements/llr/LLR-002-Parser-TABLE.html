    LLR-PARSER-001
    Reporting of incorrect input in the training data

    Any incorrect input in the training data should be reported.

    The user should be alerted when the input is incorrect, to able to correct the input. It is at the input time that the user should be alerted, not at later stages.

    Exercises can have 1..* letters in its name

    As long as the exercise contains one letter, it is a valid exercise name.

    Some synonyms, or exercise names, can be only one letter in length
